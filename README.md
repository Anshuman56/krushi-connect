# KrushiConnect

It is a platform where a farmer direct sell product to hotels or restaurant.

[Live Demo](https://krushi-connect-psi.vercel.app/)

![Screenshot](001.png "Screenshot")

## Current status (v0.1)

- You can add your email if you are interested.

## What I learned from users

- They don't use phones but there child's do so they can list there farming product there. And I don't give separate form for there child who post the list. I just keep it simple by just give the farmers name who ever list that product and there phone number.

## How to Run It Locally

```bash
git clone https://github.com/Anshuman56/krushi-connect
cd krushi-connect
npm install
create a .env.local file with you mongodb database connection.
npm run dev
```
